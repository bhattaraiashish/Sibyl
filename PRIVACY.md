# Privacy Policy

**Last updated:** October 5, 2026

Sibyl ("Sibyl", "the Bot", "we", "us", or "our") is an open-source Discord bot developed and operated by Ashish Bhattarai.

This Privacy Policy explains what information Sibyl accesses and stores when it is installed in or used within a Discord server.

## 1. Information We Collect

Sibyl only stores information that is necessary to provide its features.

Depending on which features are enabled, Sibyl may store:

* **Discord user IDs** — used to associate user-specific settings, such as timezone preferences, with a Discord user.
* **Discord server (guild) IDs** — used to associate configuration and tracked data with a particular server.
* **Discord channel IDs** — used to remember where tracked-anime notifications should be sent.
* **Anime IDs** — used to identify anime that a server has chosen to track.
* **Anime notification settings** — such as whether notifications are enabled and how frequently Sibyl checks for updates.
* **Guild feature settings** — used to determine which Sibyl features are enabled for a server.
* **Anime notification state** — such as the last episode for which a notification was sent.

Sibyl does **not intentionally store the contents of Discord messages** as part of its current functionality.

Discord may provide Sibyl with information through Discord's APIs and Gateway events as necessary for the Bot to operate. Sibyl only uses such information for the functionality described in this policy.

## 2. How We Use Information

Sibyl uses collected information only to provide and maintain its functionality, including:

* Storing server-specific configuration.
* Remembering user timezone preferences.
* Tracking anime requested by a server.
* Sending anime episode notifications to configured channels.
* Determining which features are enabled for a server.
* Responding to Discord commands and interactions.
* Maintaining the operational state required for the Bot to function.

Sibyl does not use Discord data for advertising, profiling users, or selling information.

## 3. Third-Party Services

### Discord

Sibyl operates through the Discord API and Discord's services. Discord provides the platform through which Sibyl receives commands, interactions, and other information necessary for the Bot to function.

Your use of Discord remains subject to Discord's own Terms of Service and Privacy Policy.

### AniList

Sibyl uses the AniList GraphQL API to retrieve anime information, including titles, descriptions, episode information, airing schedules, cover images, studios, and release information.

Sibyl does not send stored user profile information to AniList as part of these requests. Anime identifiers and search queries may be sent to AniList when necessary to retrieve anime information.

AniList's own terms and privacy practices apply to its services.

## 4. Data Storage

Sibyl currently stores its persistent data in a local SQLite database operated by the Bot.

The database may contain the Discord IDs and configuration data described above.

Sibyl does not intentionally store passwords, Discord authentication tokens belonging to users, payment information, or other sensitive personal information.

## 5. Data Retention

Data is retained only for as long as it is needed to provide Sibyl's functionality.

Server-specific configuration and tracked anime data may remain in the database until:

* The relevant configuration is changed or disabled;
* An anime is untracked;
* The relevant server data is removed; or
* Sibyl is removed from the server and its associated data is deleted.

Completed anime tracking records may also be automatically removed after they are no longer needed for notifications.

## 6. Data Deletion

You may request deletion of data associated with your Discord user or server.

For user-specific data, please provide your Discord user ID and the data you want deleted.

For server-specific data, a server administrator may request deletion of the server's Sibyl data.

Deletion requests can be made through the Sibyl GitHub repository or by contacting the developer.

## 7. Data Sharing

Sibyl does not sell, rent, or provide Discord user data to advertisers or data brokers.

Sibyl only sends information to third-party services when necessary to provide a feature, such as requesting anime information from AniList.

We may disclose information where required by applicable law or where necessary to protect the security and integrity of the Bot or its infrastructure.

## 8. Security

Reasonable measures are used to protect Sibyl's stored data and credentials.

However, no system can guarantee absolute security. Users should not provide Sibyl with sensitive information that is not required for its functionality.

## 9. Children's Privacy

Sibyl is not intentionally directed at children below the minimum age permitted to use Discord in their jurisdiction.

Sibyl does not intentionally collect sensitive information from children.

## 10. Changes to This Policy

This Privacy Policy may be updated when Sibyl's functionality or data practices change.

The latest version will be made publicly available at the location where this policy is published.

## 11. Contact

Sibyl is an open-source project.

For privacy questions, data deletion requests, or other concerns, contact the developer through the Sibyl GitHub repository.
